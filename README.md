# RecipeBook

RecipeBook is a web application for discovering, saving, and organizing your favorite recipes.  
Built with **Firebase**, it supports real-time database and secure recipe storage.  

---

## Features

- Categorized Recipes: Browse recipes by categories like Breakfast, Lunch, Dinner, Desserts, and more.
- Save Your Recipes: Add personal recipes and access them anytime.
- Firebase Integration: Real-time database, hosting, and storage powered by Firebase.
- Responsive Design: Works smoothly on desktop and mobile devices.

---

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Firebase (Firestore, Hosting, Functions)
- **Database**: Firestore / Realtime Database
- **Other Tools**: Firebase CLI, Node.js (for deployment scripts)
